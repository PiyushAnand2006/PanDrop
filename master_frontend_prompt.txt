- **Theme:** High-craft Dark UI ("Linear meets Apple Vision Pro meets Shopify Studio").
- **Color Palette:**
  - Background Primary: `#090A0F` (Deep Obsidian)

  - Primary Accent (Meta AI / SAM 3.1 HUD): Electric Cyan `#00F0FF` to Royal Blue `#0066FF`.

- **Typography:** `Inter` or `Plus Jakarta Sans` for UI; `JetBrains Mono` for timestamps, bounding boxes, prices, and model telemetry.

## 2. EXACT BACKEND API CONTRACT (`src/types/pandrop.ts`)
The FastAPI backend runs at `const API_BASE = import.meta.env.VITE_API_BASE_URL || "http://localhost:8000"`.
All relative asset paths returned by the backend (e.g. `"/static/jobs/..."`) MUST be resolved via a helper function `resolveAssetUrl(path: string)` that prepends `API_BASE` if the path starts with `"/"`.

```typescript
